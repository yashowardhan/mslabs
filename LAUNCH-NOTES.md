# MS Labs Studio final site

## Included
- `index.html` — broad MS Labs homepage
- `wordpress-care.html` — direct business/site-owner offer
- `development.html` — custom WordPress + React/Next.js development
- `agency-partner.html` — dedicated agency/white-label offer
- `privacy.html` and `terms.html`
- `styles.css` — one shared light/dark theme
- `site.js` — shared navigation and form logic
- `robots.txt` and `sitemap.xml`

## Before publishing
1. Confirm the form delivery provider and test a real submission. The current implementation uses FormSubmit AJAX to forward enquiries to `contact@mslabsstudio.com`.
2. Confirm the first FormSubmit activation email if the provider requests it.
3. `og-image.png` is included in this package; upload it to the site root with the HTML.
4. Add Yash's real photo if desired; the site deliberately uses initials until a real photo is supplied.
5. Register the sitemap in Google Search Console.
6. Decide on Plausible or another privacy-friendly analytics provider and add it after the account/domain is configured.
7. Have an accountant/lawyer review the privacy, terms, invoicing, GST/tax and international-client setup for the actual business entity.

## Content choices made from the review
- Homepage is no longer agency-first.
- Agency Partner is a dedicated page.
- "Most popular" changed to "Recommended".
- Unsupported "publicly visible proof" / fake social-proof language removed.
- "No downtime" changed to planned/minimal downtime language.
- "On call" changed to developer-looking-after-your-site language.
- CMR moved first in work.
- Non-result technology claims were removed from the eBay/Walmart outcome lists.
- Decorative agency meters were removed.
- Agency capacity, timezone, IP/handover, non-solicitation and post-delivery bug-fix language added.
- Free check vs paid audit is explicitly explained.
- Access/security expectations are explained.
- Homepage and agency page use "I" consistently.

- Payment is intentionally kept generic for launch; add the final payment/invoicing workflow once the first client is ready to onboard.
